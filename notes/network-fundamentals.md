## 1. Learning Objective

Understand how devices communicate over networks and learn the fundamental concepts that support cybersecurity.

## 2. Key Concepts

### IP Address
An IP address identifies a device's network interface so that traffic can be routed to the correct destination.

### MAC Address
A Media Access Control (MAC) address identifies a network interface at the data-link layer.

### DNS
The Domain Name System translates domain names, such as example.com, into IP addresses used to reach services.

### TCP and UDP
- **TCP:** Provides reliable, ordered delivery of data.
- **UDP:** Sends datagrams without guaranteeing delivery or order.

### Common Ports
- **21:** FTP control
- **22:** SSH
- **25:** SMTP
- **53:** DNS
- **80:** HTTP
- **443:** HTTPS

## 3. Why Networking Matters in Cybersecurity

Understanding network communication helps security professionals interpret traffic, investigate suspicious connections, identify exposed services, and understand how attacks may move across a network.
